# Source Notes

This repository was organized from a 123-page Splunk lab PDF supplied by the project author. The source material covers foundational SPL commands, statistics, eval functions, time functions, lookups, correlation commands, result modification, multivalue functions, macros, and SOC analyst workflows.

The 81 screenshots in `assets/screenshots/` were extracted directly from that PDF and are preserved in page order in `docs/evidence-gallery.md`. The detection files reorganize the source lab examples into portfolio-friendly use cases without presenting the lab thresholds as universal production rules.
