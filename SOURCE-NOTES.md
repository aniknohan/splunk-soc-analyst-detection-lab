# Source Notes

This repository was organized from a 123-page Splunk lab PDF supplied by the project author. The source material covers foundational SPL commands, statistics, eval functions, time functions, lookups, correlation commands, result modification, multivalue functions, macros, and SOC analyst workflows.

81 screenshots were extracted directly from that PDF (see `assets/image_manifest.csv`). 80 of them are in `assets/screenshots/` and are shown in page order in `docs/evidence-gallery.md`; the page 89 image is not included. The detection files reorganize the source lab examples into portfolio-friendly use cases without presenting the lab thresholds as universal production rules.
